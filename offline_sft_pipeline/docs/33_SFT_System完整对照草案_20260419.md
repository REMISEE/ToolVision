## 改动点标记

### 1. 前置说明区

只做了一处很小的修正：

- `f the image is misoriented` -> `If the image is misoriented`

这是 typo 修正，不改原意。

### 2. `function.description`

旧版：

```text
A unified tool for image processing using executable Python code. Supports basic operations (zoom in, resize, rotate, flip, brightness, contrast), mathematical visualizations (auxiliary lines, bounding boxes, coordinate systems, function graphs). The 'draw' variable provides drawing capabilities.
```

新版：

```text
A unified tool for image processing using executable Python code. Supports basic operations (zoom in, resize, rotate, flip, brightness, contrast), general cv2/PIL/numpy processing, and external helper functions for OCR, grounding, segmentation-based highlighting, depth estimation, and counting. The 'draw' variable provides drawing capabilities.
```

这里的变化：

- 保留“统一图像处理工具”的原结构
- 去掉和当前数据不匹配的 `mathematical visualizations`
- 加入当前真实在用的新能力：
  - OCR
  - grounding
  - segmentation-based highlighting
  - depth estimation
  - counting

### 3. `code.description`

这部分是主改动。

旧版的问题：

- 只给基础操作示例
- 没把 helper 的名字和调用方式写出来
- `flip` 示例和训练分布不一致
- “最常用操作”那句已经过时

新版做法：

- 对每个常用 helper 都按三段写：
  - 名字
  - 典型调用代码
  - 作用解释
- 保留基础操作示例
- 把 `flip` 改成：
  - `ImageOps.flip(image)`
  - `ImageOps.mirror(image)`
- 把最后一句改成：

```text
Important Hint: Zoom in, crop, rotate, flip, OCR, grounding, and counting are among the most common useful operations, and you should prioritize the simplest operation that can reveal the needed evidence.
```

这版更符合现在的导出数据，不再假设“最常见的只有 zoom / rotate / flip”。

### 4. `image_index.description`

旧版：

```text
Index of the image in the trajectory to process (0-based).
```

新版：

```text
Index of the visible image timeline to process (0-based). Root images come first, and each successful tool-returned image is appended for later steps.
```

这里的变化：

- 把“trajectory 里的图”改成更准确的“visible image timeline”
- 明确 root image 在前
- 明确 tool 返回图会追加到后续可见列表
