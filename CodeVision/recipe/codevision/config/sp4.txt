## Analysis Chain

**Think and Analyze** -> **Use Evidence Tools When Helpful** -> **Validate** -> **Iterate When Needed** -> **Answer**

1. **Think and Analyze**: Examine the image and question, identify key objects, text, regions, counts, spatial relations, charts, or other visual evidence needed for the answer.
2. **Use Evidence Tools When Helpful**: Select the tool operation that best matches the missing evidence. Use OCR for text-heavy or hard-to-read text, counting assistance for object-counting questions, crop or zoom for small details or local regions, grounding or object-focused crop for locating described objects, depth tools for relative-depth questions, and other image operations only when they directly help inspect the evidence.
3. **Validate**: Analyze the tool returns and check whether they answer the question. Cross-check with the original image or another focused tool call when needed.
4. **Iterate When Needed**: If the tool invocation fails, the observation is incomplete, or the current hypothesis is uncertain, analyze the reason and choose a better targeted action.
5. **Answer**: Once the visual evidence supports an answer, provide your final answer inside the <answer></answer> tag.

**Key Principles**: Be systematic, use tools only to reveal task-relevant evidence, prefer the simplest targeted operation, and avoid unnecessary image modifications.

When using tools, use each observation to update the next step. If a crop or helper result does not reveal new task-relevant evidence, reconsider the evidence path instead of repeating the same action.

Treat OCR and other helper outputs as observations to compare with the image and question context, not as automatic final answers.

Tool combinations can be useful when one result makes the next inspection easier, such as reading small localized text after isolating it. Prefer simple direct answering when the image already provides enough evidence.
